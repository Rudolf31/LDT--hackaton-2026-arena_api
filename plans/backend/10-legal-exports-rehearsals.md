# 10 · Право, выгрузки, репетиции

**Цель.** Кадровый контур закрыт: решения с основаниями, возражения и ответы, выгрузки CSV/XLSX
с журналом; методолог репетирует черновик по одноразовой ссылке.

**Зависит от:** 09. `rehearsals` можно делать сразу после 04 и 06 (D-07).

## Задачи

### decisions
- [ ] Кандидаты: только оценочные, завершённые, не упрощённые, проверенные сессии сотрудника.
- [ ] Запись решения: основания обязательны, не предзаполняются; ссылки на сессии; пересмотр —
      новая запись с `supersedes_id`; `decision_recorded`. Отказы триггера → 422 `decision_ineligible`
      с русским текстом.

### objections
- [ ] Подача участником (текст шифром, привязка к месту), `objection_submitted`.
- [ ] Список для HR (фильтр `id`), ответ (три поля вместе, шифр), `objection_answered`;
      повтор → 409 `already_answered`.

### exports
- [ ] Три среза, восемь фильтров в теле, итоговая (строка на сессию) и подробная (строка на
      реплику) таблицы, CSV и XLSX (Q-07); `dry_run` — только число строк.
- [ ] Журнал: строка на каждую группу с `rows_count` и общим id выгрузки (архитектура 5.2 п. 8).
- [ ] «Мало данных» и раздельные оценки в файле.

### rehearsals
- [ ] Выдача ссылки: отпечаток черновика, уровень, профиль, получатель, 30 минут; в базе только
      HMAC токена; показ один раз.
- [ ] Погашение: один `UPDATE … WHERE redeemed_at IS NULL AND link_expires_at > now()`;
      повтор → 410; ответ — документ черновика с уровнем, профиль с ключами, токен репетиции.
- [ ] Приём записи (до 5 МБ, закрытая схема, `emotion`), чтение репетиции с разбором, список.
- [ ] Заменить заглушку счётчика репетиций в `scenarios` (D-06).

## Ловушки

- `hr_decisions` — только `INSERT`; решение не правится.
- Выгрузка по нескольким группам — несколько строк журнала, не одна.
- Токен репетиции годится только для загрузки её записи.

## Готово, когда

- [ ] Пустые основания → отказ; тренировочную сессию привязать нельзя.
- [ ] Выгрузка без доступа к группе → 403 (FR-RS-10).
- [ ] Вторая попытка погасить ссылку → 410.
