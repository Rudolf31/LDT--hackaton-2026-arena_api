# 04 · Сценарии и версии

**Цель.** Методолог создаёт сценарий из шаблона, копией или каркасом, правит черновик формой,
видит проверку и публикует неизменяемую версию; библиотека, импорт, экспорт и архив работают.

**Зависит от:** 02, 03

## Задачи

- [ ] Создание: `origin` = `template` / `copy` / `manual` / `brief` (последний — пустой сценарий
      под авторство, документа ещё нет, название из `generation`).
- [ ] Черновик: чтение (документ, отпечаток, проверка), сохранение целиком с `If-Match` → 412
      `draft_changed`; проверка при каждом сохранении, результат в `draft_check`; отпечаток в
      `draft_fingerprint`; схемная ошибка — не сохраняется (FR-SC-15).
- [ ] Проверка без сохранения.
- [ ] Публикация: все правила на трёх уровнях; отпечаток совпал с последней версией → 409
      `nothing_changed`; новая версия с номером, `admission_required = 0`,
      `admission_rehearsals` = фактическое число (D-06, архитектура 12.5); `scenario_published`.
- [ ] Режим: меняется только пока версий нет (`mode_locked`); `scenario_mode_changed`.
- [ ] Версии: список, одна версия с документом. Контракт `scenarios.Version(id)` для назначений
      и сессий.
- [ ] Библиотека: фильтры по сфере, типу, режиму, статусу, поиск, теги; паспорт из
      `draft_document->'passport'` или из `generation`.
- [ ] Импорт JSON (повреждённый файл не создаёт ничего), экспорт.
- [ ] Архив и возврат (`archived: false`), `scenario_archived`.
- [ ] Шаблоны — список шести с главными весами.
- [ ] Наблюдатель видит только опубликованные (матрица ролей).

## Адреса

`GET|POST /scenarios`, `GET /scenario-templates`, `POST /scenarios/import`,
`GET /scenarios/{id}`, `GET|PUT /scenarios/{id}/draft`, `POST /scenarios/{id}/draft/check`,
`POST /scenarios/{id}/publish`, `GET /scenarios/{id}/versions`,
`GET /scenarios/{id}/versions/{n}`, `GET /scenarios/{id}/export`, `POST /scenarios/{id}/archive`

## Где читать

- `arena-portal-hr.md` 6.1 (UC-M-02…07, 09, 10), 10.5, 11.7
- `arena-portal-backend-architecture.md` 6.5, 10.1, 12.5

## Ловушки

- `scenario_versions` только `INSERT` — никаких «поправить версию».
- `slug` не уникален.
- Правка тегов не меняет отпечаток — и не должна отвязывать репетиции.

## Готово, когда

- [ ] Сценарий из каждого из пяти входов даёт черновик с одинаковым списком разделов (FR-SC-01).
- [ ] Каркас публикуется без правок (FR-SC-02).
- [ ] Экспорт → импорт → тот же отпечаток (I-13).
- [ ] Повторная публикация без изменений → 409.
