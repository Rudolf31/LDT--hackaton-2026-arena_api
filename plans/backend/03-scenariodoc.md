# 03 · Документ сценария (`scenariodoc`)

**Цель.** Чистая библиотека над документом `arena-scenario/1`: проверка схемы и пятнадцати
правил на трёх уровнях с сообщениями на языке предмета, применение уровня сложности, шаблоны,
каркас, отпечаток. Без HTTP и без базы — тестируется целиком юнит-тестами.

**Зависит от:** 00. Самый большой этап; идёт параллельно 01–02.

## Задачи

- [x] Go-типы документа и JSON Schema документа (неизвестное поле — ошибка). Схема пишется по
      `arena-portal-hr.md` 11.1 и `arena-scenario-format.md`; файла `arena-scenario.schema.json`
      нет и не будет — схема живёт в коде `scenariodoc`.
- [x] Условия: двенадцать видов узлов, разбор, проверка вида и полей, глубина ≤ 2 групп
      (`not` не считается), подходящие сравнения для типа предмета, `scope` у предметов.
- [x] Каталог узлов для конструктора и перевод условия во фразу по-русски.
- [x] Применение уровня сложности (`easy`, `hard` поверх базового) — полный список настроек
      из `arena-portal-hr.md` 11.4.
- [x] Модель диагностики: `level` (блокирующая / предупреждение), `difficulty`, `path` (JSON Pointer),
      `message` по-русски с подписями вместо идентификаторов (FR-SC-07).
- [x] Правила 1, 1а (зона сделки, старт/предел/цель; обе стороны шкалы — FR-SC-13).
- [x] Правила 2, 3 (достижимость этапов и выход из них; граф этапов).
- [x] Правило 4 (достижимость финалов, последний `always`) — приближённо.
- [x] Правила 5, 12 (уступки: `stop_at`, `step`, `unlock_cost`, предел).
- [x] Правила 6, 7 (ссылки на несуществующее; корректность условий; флаг ставится и проверяется).
- [x] Правила 8, 9, 10 (развилки и финалы; собственные ходы; скрытые факты).
- [x] Правила 13, 14, 15 (давление без очков, вес `none = 0`; интересы ≥ 0,35; прочее).
- [x] Правило 11 — прогон 1–10 и схемы на каждом уровне; предупреждение про тип хода и факт.
- [x] Отпечаток: SHA-256 от канонического JSON без `passport.version`, `passport.tags`,
      `passport.origin`, `authoring`.
- [x] Шесть шаблонов + демо-шаблон + каркас «вручную» — JSON-файлы внутри пакета (`embed`).
- [x] Выборка паспорта (название, сфера, тип, теги) для библиотеки.

## Тесты

- [x] По сценарию-нарушителю на каждое правило (I-12); в исходной спецификации их 28 —
      ориентир `arena-scenario-format.md`.
- [x] Каждый шаблон и каркас проходят проверку без блокирующих ошибок на трёх уровнях.
- [x] «Закупка»: вес предложения конкурента > внутреннего правила; «Внутреннее повышение» — наоборот
      (FR-SC-12); предел выше старта во «Внутреннем повышении» принимается (FR-SC-13).
- [x] Отпечаток: стабилен; меняется от байта разговора; не меняется от тегов, `origin`,
      `authoring`, `passport.version` (I-13).
- [x] Ни одно сообщение не содержит голого идентификатора без подписи.
