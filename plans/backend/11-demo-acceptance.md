# 11 · Демо и приёмка

**Цель.** Клон и одна команда меньше чем за десять минут: портал поднимается с демо-данными,
все экраны непустые, гость проходит демо без кода.

**Зависит от:** 10; перед началом закрыть Q-02 и Q-03 в `decisions.md`.

## Задачи

### demo
- [ ] `POST /api/trainer/demo/enter`: гостевой токен с `demo_guest_id`, демо-сценарий, профиль
      по умолчанию; ключи — только при `DEMO_MODEL_KEYS=1`; `ARENA_DEMO=0` → 404 `demo_disabled`;
      частота 10/мин с адреса.
- [ ] Демо-сессии: `is_demo`, без назначения и группы, только тренировка, на одном
      демо-участнике; гость видит только свои сессии.

### демо-данные (NFR-D-04)
- [ ] Пользователи, демо-группа и четыре сотрудника уже заливаются с этапа 02 (D-23) — дополнить
      ту же заливку (`db/seed/`, модуль `demo`), а не писать заново.
- [ ] Заливка **кодом приложения** при пустой базе (нет ни одного пользователя), отпечатки
      считает `scenariodoc`; модели не вызываются.
- [ ] Состав по `arena-portal-backend-architecture.md` 11.3: настройки, методолог и администратор,
      профиль по умолчанию без ключа, группа с доступом методолога, четыре вымышленных
      сотрудника и демо-участник, четыре текста согласий, два сценария разных типов, три
      репетиции с записью, четыре назначения (код активного — в README), ответы на согласия,
      три завершённые сессии с разными финалами (одна — с нарушением без «просмотрено»),
      одно возражение без ответа, записи журнала.
- [ ] Вариант второго сценария — по Q-02.

### приёмка
- [ ] README репозитория: одна команда запуска, логины демо, код активного назначения.
- [ ] Сверка: все 84 адреса архитектуры 13.2 зарегистрированы, отменённые — нет (I-16).
- [ ] Таблица NFR-PR-03 заполнена, тест по столбцам зелёный (I-10); пропуск `TestRetentionMatchesSchema` без `ARENA_TEST_RETENTION=1` снят (`db/schema/retention_integration_test.go`).
- [ ] Прогон всех тестов из `invariants.md`.
- [ ] Замер «клон → работает» на чистой машине; ни одного обращения к хостам третьей стороны
      при сборке и первом запуске.
- [ ] Выборочно NFR-P-01: чтение ≤ 200 мс, запись ≤ 500 мс на демо-данных.

## Ловушки

- Гостю ключи не отдаются по умолчанию — иначе любой уносит ключи.
- Демо не должно менять ни одной цифры статистики (I-6).
- Демо-данные не SQL-скриптом, а тем же кодом, что в работе.
