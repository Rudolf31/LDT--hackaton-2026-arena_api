# 08 · Разговор

**Цель.** Сессия проходится от первой реплики до завершения и сохраняется целиком: лог ходов
с решениями судей, счётчики и пометки, обе оценки с клиента; брошенные сессии закрывает сервер,
поздние события открывают их заново.

**Зависит от:** 07

## Задачи

### sessions — события хода
- [ ] Пачка до 100 событий, закрытая схема, фильтр `emotion` (I-1).
- [ ] Одна транзакция по архитектуре 7.2: вставка `turns` (дубли по `(session_id, seq)`
      отбрасываются), шифр текстов ключом участника (ключ уничтожен → `text_enc = NULL`),
      `comment` судьи оппонента — в отдельный шифр, обновление счётчиков и `incidents`,
      `simplified` снимает отметку «просмотрено», переоткрытие `abandoned`.
- [ ] Идёт другая сессия по тому же назначению → ходы пишутся, статус остаётся, `reopened = false`.
- [ ] Отменённое назначение: события идущей сессии принимаются.

### sessions — завершение и судья
- [ ] Завершение: итоговый статус, причина, блок оценок; проверка **только формы** по таблице
      архитектуры 8.2; раскладка по столбцам по 8.3; `scores` без цитат; ответ судьи как
      пришёл — в шифр; `missing_turns` при недошедших ходах; повтор возвращает сохранённое.
- [ ] `process_status` по `arena-portal-hr.md` 10.2.
- [ ] `judge-retry`: данные для повторного запроса (транскрипт, решения, предложения, интересы,
      тексты раскрытых фактов).
- [ ] `judge-answer`: приём ответа; сохранённый и проверенный → 409 `already_answered`.

### jobs
- [ ] Раз в минуту — закрытие брошенных сессий запросом из архитектуры 7.3 с
      `greatest(last_event_at, $portal_started_at)`; `session_closed_by_server` по каждой.
- [ ] Сброс зависших генераций при старте (если не сделан в 05).

## Адреса

`POST /api/trainer/sessions/{id}/events`, `POST /api/trainer/sessions/{id}/finish`,
`GET /api/trainer/sessions/{id}/judge-retry`, `POST /api/trainer/sessions/{id}/judge-answer`

## Ловушки

- Никакого пересчёта и сверки оценок (`CLAUDE.md`).
- Никакого поля суммы двух оценок (I-2); буква только с финалом.
- У `abandoned` оценок нет — ограничение базы.
- Заполнители не пишутся; решение судьи дописать потом нельзя.

      статус (FR-AC-11).
- [ ] Тест I-15 (таймаут не считает время недоступности).
- [ ] Повторная пачка не дублирует ходы.
