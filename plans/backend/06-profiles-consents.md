# 06 · Профили тренажёра и согласия

**Цель.** Администратор ведёт профили с ключами (видны только последние 4 знака), есть профиль
по умолчанию; портал знает тексты согласий и умеет подобрать нужный вариант для участника
и принять ответ.

**Зависит от:** 02

## Задачи

Решения этапа — D-42…D-49 в [decisions.md](decisions.md).

### profiles
- [x] Закрытая схема `settings` (адреса моделей, модели оппонента и двух судей, речь, режим ввода,
      камера и `emotion_labels_to_opponent`, лимиты ходов, времени, длины ответа, окно контекста).
- [x] Проверки UC-A-01: длина ответа задана (окно контекста не сверяется — D-42).
- [x] Создание и копия, правка с ростом `revision`, архив (профиль по умолчанию — нельзя).
- [x] Ключи: отдельный адрес только на запись; шифр мастер-ключом + `_last4`;
      `profile_key_changed` в журнал.
- [x] Ответы не-администраторам — из `trainer_profiles_public` (без ключей и last4).
- [x] Наследование пустых полей из профиля по умолчанию.
- [x] Контракт для `sessions`/`rehearsals`: `SnapshotWithKeys(profileID, externalAIAllowed)`
      — снимок, ревизия и ключи; без согласия — без адреса и ключа OpenRouter.
- [x] «Проверить профиль» — заглушка `ProfileChecker`, четыре строки «не проверялось»
      (архитектура 10.3).

### consents
- [x] Тексты согласий и уведомлений (`consent_texts`, только новые версии, `body_sha256`);
      начальные тексты — в демо-данных (файла `arena-consent-texts.md` нет, тексты пишем сами
      по реквизитам ст. 9 ч. 4 152-ФЗ, `arena-portal-hr.md` 13.1).
- [x] Выбор варианта А/Б/В по режиму и профилю, подстановки (куда уходят данные — из профиля,
      FR-AC-13).
- [x] Контракт для `sessions`: `TextsFor(assignment)`, `Usable(subject, assignment, kind)`.
- [x] Приём ответа участника: вид, версия, `shown_text_hmac` на ключе участника, время; отказ
      тоже пишется; повтор — ещё одна безвредная запись.
- [x] Письменное согласие от HR (`written_assessment`, реквизиты бумаги), `written_consent_recorded`.

## Адреса

`profiles`: `GET|POST /trainer-profiles`, `GET|PATCH /trainer-profiles/{id}`,
`PUT /trainer-profiles/{id}/keys`, `POST /trainer-profiles/{id}/check`,
`POST /trainer-profiles/{id}/archive`
`consents`: `POST /api/trainer/consents`, `POST /api/portal/people/{subjectId}/written-consents`

`POST /api/trainer/consents` требует токен участника из этапа 07 — обработчик пишется здесь,
сквозной тест — в 07.

- Ключ целиком не возвращается ни одному адресу портала (I-9).
- `emotion_labels_to_opponent` — законное поле; `emotion` — нет (I-1).
