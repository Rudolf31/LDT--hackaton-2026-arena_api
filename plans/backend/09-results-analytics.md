# 09 · Результаты и аналитика

**Цель.** HR видит результат сессии с раскрытием любого числа до цитаты, запись сессии,
урезанный вид без доступа; участник видит свои результаты; раздел статистики строится
по сессиям без демо.

**Зависит от:** 08. `results` и `analytics` — две дорожки.

## Задачи

### results
- [ ] Контракт `sessions` на чтение (списки, одна сессия, ходы) — `results` своих `SELECT`
      по чужим таблицам не делает.
- [ ] Список сессий групп с доступом (фильтр чужой группы → 403).
- [ ] Результат для HR: обе оценки раздельно, финал с буквой и эпилогом, эпизоды со ссылкой
      на реплики, «повезло», пометки, возражения; `session_opened` в журнал.
- [ ] Запись сессии: ходы, шкалы, решения судей, снимок профиля, адрес моделей, отказы
      компонентов; тексты расшифровываются, при уничтоженном ключе — «текст удалён по отзыву
      согласия».
- [ ] Урезанный вид — **отдельная проекция** без имени и текстов (FR-ST-02);
      `session_reduced_opened`.
- [ ] «Просмотрено»: только завершённая сессия с нарушениями; иначе 409; с именем проверившего.
- [ ] Участник: свои попытки и разбор одной сессии; гость — только по номеру гостя;
      пошаговый разбор хода участнику по назначению не отдаётся (NFR-M-02).

### analytics
- [ ] Здоровье версии (FR-ST-01) и сессии с проблемой — запросы из `arena-db.md` 7.
- [ ] Сравнение в равных условиях: режим, версия, уровень, набор критериев, профиль оценки;
      неполные условия → 200 со списком сочетаний; упрощённые исключены по умолчанию.
- [ ] Аналитика групп: слабые критерии готовой фразой, распределение оценок, вторая группа —
      только при равных версии и уровне.
- [ ] Сессии по критерию с примерами цитат.
- [ ] Динамика сотрудника: линия на пару «версия + уровень»; меньше трёх попыток — без вывода.
- [ ] Пометка «мало данных (n = …)» при n < 30 — ставит бэкенд.
- [ ] `NOT is_demo` в каждом запросе (I-6).

## Ловушки

- Никаких «общих итогов», средних двух оценок, сортировки по сумме (I-2).
- Урезанный вид — не «тот же ответ минус поля».
- Отмечать «просмотрено» у идущей или прерванной сессии нельзя.
