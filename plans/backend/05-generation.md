# 05 · Авторство голосом и текстом

**Цель.** Сценарий надиктовывается голосом или присылается текстом и превращается в документ,
прошедший проверку; готовый черновик правится голосовым или текстовым указанием. Без
настроенных моделей портал работает, а четыре адреса отвечают 503.

**Зависит от:** 04

## Задачи

### platform/ai
- [ ] `Transcriber` — HTTP-клиент к совместимому с OpenAI адресу расшифровки (`ARENA_STT_*`).
- [ ] `ScenarioGenerator.Generate(brief, base, problems)` — структурированный ответ по схеме
      документа из `scenariodoc` (`ARENA_GEN_*`). Через библиотеку
      [`github.com/revrost/go-openrouter`](https://pkg.go.dev/github.com/revrost/go-openrouter)
      (OpenRouter), не самописным HTTP-клиентом (D-13). `Transcriber` ниже это не касается.
- [ ] Нет переменных → доменная ошибка «не настроено» → 503 `generation_unavailable`
      «Модель генерации не настроена».
- [ ] Тестовый двойник обеих моделей для тестов.

### generation
- [ ] Адреса пишутся **руками на `chi`** (D-05), со схемами тел в коде; multipart с одним
      файлом, до 25 МБ; mp3 только в памяти.
- [ ] Задание в фоне: `transcribing` (пропуск для текста) → `generating` → `checking`;
      состояние в `scenarios.generation` (`input_kind, status, stage, transcript, instruction,
      attempts, check, error, started_at`).
- [ ] Проверка через `scenariodoc.Validate`; ошибки текстом обратно в модель, не больше двух
      повторов; дальше черновик сохраняется с ошибками для правки в форме.
- [ ] Правка по указанию: текущий документ + указание → документ целиком → та же проверка.
- [ ] Одно задание на сценарий за раз (409 при идущем).
- [ ] Частота 10 в час на пользователя на все четыре адреса.
- [ ] При старте портала: `running` → `failed` «Портал перезапускался — повторите».
- [ ] Результат записывается в черновик через контракт `scenarios` (владелец таблицы — `scenarios`).

## Ловушки

- mp3: ни в базу, ни на диск, ни в лог; не использовать `ParseMultipartForm` с записью во
  временные файлы — читать часть потоком в память с лимитом.
- Расшифровку не класть в `audit_log.details` и в лог (I-11).
- Анкеты из десяти полей и шагов с подтверждением **нет**.
- Модели портал вызывает только здесь; в цикле разговора — никогда.

## Готово, когда

- [ ] Без `ARENA_STT_*`/`ARENA_GEN_*` портал стартует, четыре адреса → 503, форма и шаблоны работают.
- [ ] С двойником модели: текст → документ, проходящий проверку; неверный документ → два повтора
      → черновик с диагностикой.
- [ ] Тест I-11 зелёный.
- [ ] Перезапуск во время задания → состояние `failed` с русским текстом.
