# 07 · Назначения и вход в тренажёр

**Цель.** HR назначает версию сценария сотруднику или группе и получает коды; сотрудник вводит
код в тренажёре, даёт согласие и стартует сессию — получает документ целиком, уровень, снимок
профиля и ключи. Три запроса до первой реплики (NFR-P-02).

**Зависит от:** 04, 06

## Задачи

### assignments
- [ ] Создание одному и списку: версия, уровень, профиль (по умолчанию — профиль группы),
      срок; `group_id` на момент назначения; для оценки без ФИО — «не назначено» (частичный
      успех, FR-AC-05); `assignment_created`, `code_issued`.
- [ ] Код `ARENA-XXXX-XXXX-XXX`: 10 символов Crockford Base32 + контрольный; в базе только
      `selector_hash` и `code_hash`; каждый код через `SAVEPOINT`, до пяти попыток при коллизии
      селектора (архитектура 6.3). Код показывается один раз.
- [ ] Перевыпуск одному и нескольким: старый `revoked_at` + новый в одной транзакции.
- [ ] Отмена, продление срока, снятие блокировки (только админ).
- [ ] Список со статусом, **выводимым** по порядку из `arena-portal-hr.md` 10.4.
- [ ] Контракт для `people`: отмена назначений и кодов при отзыве согласия (заменить заглушку из 02).

### sessions — вход и старт
- [ ] `POST /trainer/enter`: частота 10/мин с адреса; поиск по селектору → сверка хеша →
      `failed_attempts` → блокировка на пороге из настроек (`code_blocked`); 404/410 по
      `arena-portal-hr.md` 8.1; токен участника (12 ч); ответ: документ, профиль без ключей,
      тексты согласий и что делать дальше (начать / продолжить / результаты).
- [ ] `POST /trainer/sessions`: проверка согласий (`consent_required`), документ версии с
      применённым уровнем, снимок профиля и ключи (по согласию на внешнюю нейросеть,
      `no_model_route` при отсутствии маршрута); повтор старта возвращает идущую сессию
      (частичный индекс «одна идущая на назначение»).
- [ ] `GET /trainer/sessions/{id}/private` — повторная выдача после F5 (документ и доступ
      к моделям; деления на половины нет).
- [ ] Отменённое назначение или перевыпущенный код: новые сессии не начинаются, идущая доигрывается.
- [ ] Частота 30/мин на токен.

## Адреса

`assignments`: `GET|POST /assignments`, `POST /assignments/reissue-codes`,
`PATCH /assignments/{id}`, `POST /assignments/{id}/cancel`, `POST /assignments/{id}/unblock-code`
`sessions`: `POST /api/trainer/enter`, `POST /api/trainer/sessions`,
`GET /api/trainer/sessions/{id}/private`

## Ловушки

- Код в открытом виде нигде не хранится и не логируется.
- Режим назначения не хранится — берётся из версии.
- Назначение ссылается на версию; новая публикация его не двигает (FR-AC-01).
- Роль/статус назначения в токене не хранится — проверка по базе.
