# Журнал решений

Решения, принятые по ходу реализации, и вопросы, которые ещё надо закрыть. Решения из
`CLAUDE.md` («Действующие решения») здесь не повторяются — они действуют по умолчанию.

Новое решение — новая строка с номером. Закрыл открытый вопрос — перенеси его в «Принятые»
и укажи, чем закрыт.
